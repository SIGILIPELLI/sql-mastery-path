# SQL Mastery Path

A free, structured, module-wise SQL training program — entry level to master level, with runnable queries in every module (via `sqlite3`, no server setup) and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/sql-mastery-path/

## Contents

- **Level 1 · Entry** — query foundations
- **Level 2 · Intermediate** — joins, views, transactions
- **Level 3 · Advanced** — window functions, CTEs, schema design
- **Level 4 · Master** — performance, security, architecture

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
